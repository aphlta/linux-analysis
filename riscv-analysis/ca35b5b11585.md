### 2.2 功能描述

此patch为RISC-V hwprobe机制添加了对vector crypto ISA扩展的支持，使用户空间程序能够检测和使用这些加密相关的向量扩展。这些扩展定义在"RISC-V Cryptography Extensions Volume II"规范中。

## 3. 详细技术分析

### 3.1 支持的Vector Crypto扩展

此patch添加了以下10个vector crypto ISA扩展的hwprobe支持：

#### 3.1.1 基础扩展
- **Zvbb**: Vector Basic Bit-manipulation - 向量基础位操作
- **Zvbc**: Vector Carryless Multiplication - 向量无进位乘法
- **Zvkb**: Vector Cryptography Bit-manipulation - 向量加密位操作
- **Zvkg**: Vector GCM/GMAC - 向量GCM/GMAC算法
- **Zvkt**: Vector Data-Independent Execution Latency - 向量数据无关执行延迟

#### 3.1.2 NIST算法套件
- **Zvkned**: NIST Suite: Vector AES Block Cipher - NIST套件：向量AES块密码
- **Zvknha**: NIST Suite: Vector SHA-2 Secure Hash (SHA-256) - NIST套件：向量SHA-2安全哈希
- **Zvknhb**: NIST Suite: Vector SHA-2 Secure Hash (SHA-512) - NIST套件：向量SHA-2安全哈希

#### 3.1.3 ShangMi算法套件
- **Zvksed**: ShangMi Suite: SM4 Block Cipher - 商密套件：SM4块密码
- **Zvksh**: ShangMi Suite: SM3 Secure Hash - 商密套件：SM3安全哈希

### 3.2 代码修改分析

#### 3.2.1 头文件修改 (arch/riscv/include/uapi/asm/hwprobe.h)

```c
+#define                RISCV_HWPROBE_EXT_ZVBB          (1 << 17)
+#define                RISCV_HWPROBE_EXT_ZVBC          (1 << 18)
+#define                RISCV_HWPROBE_EXT_ZVKB          (1 << 19)
+#define                RISCV_HWPROBE_EXT_ZVKG          (1 << 20)
+#define                RISCV_HWPROBE_EXT_ZVKNED        (1 << 21)
+#define                RISCV_HWPROBE_EXT_ZVKNHA        (1 << 22)
+#define                RISCV_HWPROBE_EXT_ZVKNHB        (1 << 23)
+#define                RISCV_HWPROBE_EXT_ZVKSED        (1 << 24)
+#define                RISCV_HWPROBE_EXT_ZVKSH         (1 << 25)
+#define                RISCV_HWPROBE_EXT_ZVKT          (1 << 26)
```

**分析:**
- 为每个vector crypto扩展分配了唯一的位标志
- 位标志从17-26，延续了之前scalar crypto扩展的编号
- 使用位掩码方式便于用户空间进行快速检测

#### 3.2.2 系统调用实现修改 (arch/riscv/kernel/sys_riscv.c)

```c
+               if (has_vector()) {
+                       EXT_KEY(ZVBB);
+                       EXT_KEY(ZVBC);
+                       EXT_KEY(ZVKB);
+                       EXT_KEY(ZVKG);
+                       EXT_KEY(ZVKNED);
+                       EXT_KEY(ZVKNHA);
+                       EXT_KEY(ZVKNHB);
+                       EXT_KEY(ZVKSED);
+                       EXT_KEY(ZVKSH);
+                       EXT_KEY(ZVKT);
+               }
```

**关键设计决策:**
- **条件检查**: 只有在`has_vector()`返回true时才暴露这些扩展
- **逻辑合理性**: vector crypto扩展依赖于基础的vector扩展支持
- **性能考虑**: 避免在不支持vector的系统上进行无意义的检查

### 3.3 设计原理分析

#### 3.3.1 hwprobe机制

hwprobe是RISC-V特有的硬件探测接口，允许用户空间程序：
- 查询CPU支持的ISA扩展
- 获取硬件特性信息
- 进行运行时优化决策

#### 3.3.2 Vector依赖性检查

```c
if (has_vector()) {
    // 只有在支持vector时才暴露vector crypto扩展
}
```

这个设计确保了：
- **逻辑一致性**: vector crypto扩展必须依赖基础vector支持
- **错误预防**: 防止在不支持vector的系统上错误地报告支持vector crypto
- **性能优化**: 减少不必要的检查开销
