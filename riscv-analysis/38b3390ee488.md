## 2. 代码修改原理

### 2.1 Steal-Time概念
Steal-time是虚拟化环境中的重要概念：
- **定义**: 虚拟CPU应该运行但被hypervisor调度给其他任务的时间
- **用途**: 帮助guest OS准确计算CPU使用率和进行性能分析
- **实现**: 通过guest和host之间的共享内存区域传递信息

### 2.2 SBI STA扩展
SBI (Supervisor Binary Interface) STA (Steal Time Accounting) 扩展：
- **标准化**: 为RISC-V架构提供标准化的steal-time接口
- **兼容性**: 确保不同RISC-V hypervisor实现之间的兼容性
- **效率**: 通过共享内存避免频繁的hypercall开销

### 2.3 数据结构设计

#### 2.3.1 共享内存结构
根据SBI STA规范，共享内存区域包含：
```c
struct sbi_sta_struct {
    u32 sequence;    // 序列号，确保数据一致性
    u32 flags;       // 标志位
    u64 steal;       // 累计steal时间
    u8 preempted;    // 抢占状态
    u8 pad[47];      // 填充到64字节对齐
} __packed;
```

#### 2.3.2 VCPU状态管理
在`kvm_vcpu_arch`中添加的`sta`结构：
- `shmem`: 存储guest物理地址，指向上述共享内存结构
- `last_steal`: 缓存上次记录的steal时间，用于增量更新

### 2.4 地址有效性管理

#### 2.4.1 INVALID_GPA定义
```c
#define INVALID_GPA (~(gpa_t)0)  // 定义在include/linux/kvm_types.h
```

#### 2.4.2 状态转换
- **初始状态**: `shmem = INVALID_GPA`，表示未配置
- **配置状态**: guest通过SBI调用设置有效的GPA地址
- **重置状态**: VCPU重置时回到初始状态

## 3. 技术实现细节

### 3.1 内存管理

#### 3.1.1 地址转换
```c
gfn_t gfn = shmem >> PAGE_SHIFT;
hva = kvm_vcpu_gfn_to_hva(vcpu, gfn);
```
- 将GPA转换为GFN (Guest Frame Number)
- 通过KVM内存管理接口转换为HVA (Host Virtual Address)

#### 3.1.2 内存访问安全
```c
if (WARN_ON(kvm_is_error_hva(hva))) {
    vcpu->arch.sta.shmem = INVALID_GPA;
    return;
}
```
- 检查HVA的有效性
- 出错时自动重置为无效状态

### 3.2 数据一致性保证

#### 3.2.1 序列号机制
```c
sequence = le32_to_cpu(sequence_le);
sequence += 1;
put_user(cpu_to_le32(sequence), sequence_ptr);
// ... 更新steal时间 ...
sequence += 1;
put_user(cpu_to_le32(sequence), sequence_ptr);
```

**原理**:
- 更新前递增序列号(奇数表示正在更新)
- 更新steal时间数据
- 更新后再次递增序列号(偶数表示更新完成)
- Guest可以通过检查序列号确保读取到一致的数据

#### 3.2.2 字节序处理
- 使用`le32_to_cpu()`和`cpu_to_le32()`处理字节序
- 确保在不同字节序的host和guest之间正确传递数据

### 3.3 性能优化

#### 3.3.1 增量更新
```c
u64 last_steal = vcpu->arch.sta.last_steal;
vcpu->arch.sta.last_steal = READ_ONCE(current->sched_info.run_delay);
steal += vcpu->arch.sta.last_steal - last_steal;
```

**优势**:
- 只计算自上次更新以来的增量
- 避免重复计算，提高效率
- 减少数值溢出的风险

#### 3.3.2 快速路径检查
```c
if (shmem == INVALID_GPA)
    return;
```
- 在函数入口快速检查有效性
- 避免无效配置时的不必要计算
