## 3. Zacas扩展技术背景

### 3.1 Zacas扩展概述

Zacas (Atomic Compare-and-Swap) 是RISC-V架构的一个标准扩展，提供原子比较交换指令支持。<mcreference link="https://github.com/riscv/riscv-isa-manual/blob/main/src/zacas.adoc" index="2">2</mcreference>

### 3.2 主要功能特性

1. **原子操作支持**: 提供硬件级别的原子比较交换操作
2. **多数据宽度**: 支持32位、64位和128位（仅RV64）数据值的CAS操作 <mcreference link="https://github.com/riscv/riscv-isa-manual/blob/main/src/zacas.adoc" index="2">2</mcreference>
3. **线程同步**: 为无锁和无等待算法提供硬件支持 <mcreference link="https://github.com/riscv/riscv-isa-manual/blob/main/src/zacas.adoc" index="2">2</mcreference>
4. **C++11兼容**: 支持C++11原子比较交换操作 <mcreference link="https://github.com/riscv/riscv-isa-manual/blob/main/src/zacas.adoc" index="2">2</mcreference>

### 3.3 指令集详情

- **AMOCAS.W**: 32位原子比较交换
- **AMOCAS.D**: 64位原子比较交换  
- **AMOCAS.Q**: 128位原子比较交换（仅RV64）

### 3.4 依赖关系

Zacas扩展依赖于Zaamo扩展。<mcreference link="https://github.com/riscv/riscv-isa-manual/blob/main/src/zacas.adoc" index="2">2</mcreference>

## 4. 代码实现原理

### 4.1 ISA扩展检测机制

内核通过以下步骤检测和启用ISA扩展：

1. **设备树解析**: 从设备树的`riscv,isa-extensions`属性中读取扩展列表
2. **字符串匹配**: 将扩展名字符串与`riscv_isa_ext`数组中的条目进行匹配
3. **位图设置**: 在CPU的ISA扩展位图中设置对应的扩展位
4. **特性启用**: 根据检测结果启用相应的内核特性

### 4.2 数据结构设计

```c
struct riscv_isa_ext_data {
    const char *name;           // 扩展名称字符串
    unsigned int isa_ext_id;    // 扩展ID
    // 其他字段...
};
```

### 4.3 宏定义机制

`__RISCV_ISA_EXT_DATA`宏简化了扩展数据结构的定义：

```c
#define __RISCV_ISA_EXT_DATA(name, id) \
    { .name = #name, .isa_ext_id = id }
```

## 7. 技术细节和注意事项

### 7.1 内存一致性

Zacas指令支持acquire/release语义，通过aq和rl位控制内存排序。<mcreference link="https://github.com/riscv/riscv-isa-manual/blob/main/src/zacas.adoc" index="2">2</mcreference>

### 7.2 寄存器对使用

对于128位操作，Zacas使用寄存器对来源比较值，需要特别注意寄存器分配和使用。<mcreference link="https://github.com/riscv/riscv-isa-manual/blob/main/src/zacas.adoc" index="2">2</mcreference>

### 7.3 PMA支持级别

Zacas定义了三个额外的PMA支持级别：AMOCASW、AMOCASD和AMOCASQ。<mcreference link="https://github.com/riscv/riscv-isa-manual/blob/main/src/zacas.adoc" index="2">2</mcreference>
