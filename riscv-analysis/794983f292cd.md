## 修改概述

这个patch为RISC-V架构的hwprobe系统调用添加了对标量密码学ISA扩展的支持，通过hwprobe接口导出了9个标量密码学扩展。

### 涉及的文件

1. **Documentation/arch/riscv/hwprobe.rst** (+27行)
2. **arch/riscv/include/uapi/asm/hwprobe.h** (+9行)
3. **arch/riscv/kernel/sys_riscv.c** (+10行)

总计：46行新增代码

## 详细修改内容

### 1. 文档更新 (Documentation/arch/riscv/hwprobe.rst)

为以下9个标量密码学扩展添加了文档说明：

- **Zbkb**: 位操作密码学扩展
- **Zbkc**: 进位无关乘法密码学扩展
- **Zbkx**: 交叉乘法密码学扩展
- **Zknd**: NIST AES解密扩展
- **Zkne**: NIST AES加密扩展
- **Zknh**: NIST SHA2哈希扩展
- **Zksed**: ShangMi SM4块密码扩展
- **Zksh**: ShangMi SM3哈希扩展
- **Zkt**: 数据无关执行延迟扩展

### 2. 用户空间API定义 (arch/riscv/include/uapi/asm/hwprobe.h)

在`RISCV_HWPROBE_KEY_IMA_EXT_0`键下新增了9个位掩码定义：

```c
#define RISCV_HWPROBE_EXT_ZBKB          (1 << 8)
#define RISCV_HWPROBE_EXT_ZBKC          (1 << 9)
#define RISCV_HWPROBE_EXT_ZBKX          (1 << 10)
#define RISCV_HWPROBE_EXT_ZKND          (1 << 11)
#define RISCV_HWPROBE_EXT_ZKNE          (1 << 12)
#define RISCV_HWPROBE_EXT_ZKNH          (1 << 13)
#define RISCV_HWPROBE_EXT_ZKSED         (1 << 14)
#define RISCV_HWPROBE_EXT_ZKSH          (1 << 15)
#define RISCV_HWPROBE_EXT_ZKT           (1 << 16)
```

### 3. 内核实现 (arch/riscv/kernel/sys_riscv.c)

在`hwprobe_isa_ext0()`函数中添加了对这9个扩展的检测和导出：

```c
EXT_KEY(ZBKB);
EXT_KEY(ZBKC);
EXT_KEY(ZBKX);
EXT_KEY(ZKND);
EXT_KEY(ZKNE);
EXT_KEY(ZKNH);
EXT_KEY(ZKSED);
EXT_KEY(ZKSH);
EXT_KEY(ZKT);
```

## 修改原理分析

### 技术背景

1. **RISC-V密码学扩展标准化**: RISC-V密码学扩展已经标准化，包括标量和向量两大类
2. **hwprobe系统调用**: RISC-V特有的系统调用，用于查询处理器特性和ISA扩展支持情况
3. **用户空间需求**: 密码学库和应用程序需要在运行时检测可用的密码学指令

### 实现原理

1. **统一的扩展检测框架**: 使用现有的`EXT_KEY`宏模式，保持与其他ISA扩展一致的实现方式
2. **位掩码设计**: 每个扩展占用一个位，支持高效的位运算检测
3. **用户空间接口**: 通过UAPI头文件提供稳定的用户空间接口
4. **文档完整性**: 确保每个新增扩展都有完整的文档说明

### 密码学扩展分类

#### 基础位操作扩展
- **Zbkb**: 提供密码学常用的位操作指令
- **Zbkc**: 提供进位无关的乘法运算
- **Zbkx**: 提供交叉乘法运算

#### NIST标准算法扩展
- **Zknd**: AES解密指令
- **Zkne**: AES加密指令  
- **Zknh**: SHA-256/SHA-512哈希指令

#### 中国商密算法扩展
- **Zksed**: SM4块密码指令
- **Zksh**: SM3哈希指令

#### 安全特性扩展
- **Zkt**: 数据无关执行延迟，防止时序攻击

### 用户空间使用示例

```c
#include <sys/syscall.h>
#include <asm/hwprobe.h>

struct riscv_hwprobe pairs[] = {
    {.key = RISCV_HWPROBE_KEY_IMA_EXT_0, .value = 0}
};

syscall(__NR_riscv_hwprobe, pairs, 1, 0, NULL, 0);

if (pairs[0].value & RISCV_HWPROBE_EXT_ZKNE) {
    // 使用AES加密指令
}
if (pairs[0].value & RISCV_HWPROBE_EXT_ZKNH) {
    // 使用SHA哈希指令
}
```
