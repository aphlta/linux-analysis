## 核心技术原理

### 1. RISC-V重定位机制

RISC-V架构支持多种重定位类型，用于在模块加载时修正地址引用：

- **SET重定位 (R_RISCV_SET_*)**: 将目标地址直接设置到指定位置
- **SUB重定位 (R_RISCV_SUB_*)**: 从当前值中减去目标地址
- **ADD重定位 (R_RISCV_ADD_*)**: 将目标地址加到当前值

### 2. ULEB128编码原理

ULEB128（Unsigned Little Endian Base 128）是一种变长编码格式：
- 每个字节的低7位存储数据
- 最高位作为继续位（1表示后续还有字节，0表示结束）
- 用于高效存储可变大小的无符号整数

在模块重定位中的应用：
```assembly
.reloc second, R_RISCV_SET_ULEB128, second
.reloc second, R_RISCV_SUB_ULEB128, first
```
这对重定位计算 `second - first` 的距离并以ULEB128格式存储。

### 3. 重定位处理流程

在内核模块加载过程中：
1. 解析ELF重定位表
2. 根据重定位类型调用相应处理函数
3. 对于ULEB128，使用累积处理机制
4. 最终将计算结果编码为ULEB128格式
