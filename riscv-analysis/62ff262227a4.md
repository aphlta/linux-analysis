## 2. 修改内容概述

这个patch将RISC-V架构中的CPU操作从per-CPU数组模式改为全局单一指针模式，主要修改包括：

### 2.1 头文件修改 (arch/riscv/include/asm/cpu_ops.h)
- 将 `extern const struct cpu_operations *cpu_ops[NR_CPUS];` 改为 `extern const struct cpu_operations *cpu_ops;`
- 修改 `cpu_set_ops()` 函数签名，移除 `cpuid` 参数

### 2.2 实现文件修改 (arch/riscv/kernel/cpu_ops.c)
- 将 `cpu_ops` 从数组改为单一指针：`const struct cpu_operations *cpu_ops __ro_after_init = &cpu_ops_spinwait;`
- 简化 `cpu_set_ops()` 函数实现：
  - 移除 `cpuid` 参数
  - 移除条件判断 `if (!cpuid)`
  - 直接设置全局 `cpu_ops` 指针
  - 移除 `else` 分支中的 spinwait 设置

### 2.3 SMP相关修改

#### arch/riscv/kernel/smp.c
- 在 `ipi_cpu_crash_stop()` 函数中，将 `cpu_ops[cpu]->cpu_stop()` 改为 `cpu_ops->cpu_stop()`

#### arch/riscv/kernel/smpboot.c
- 在 `setup_smp()` 函数中：
  - 调用 `cpu_set_ops()` 时移除参数
  - 移除循环中对每个CPU的 `cpu_set_ops(cpuid)` 调用
- 在 `start_secondary_cpu()` 函数中，将 `cpu_ops[cpu]->cpu_start` 改为 `cpu_ops->cpu_start`

## 3. 技术原理分析

### 3.1 问题背景

在RISC-V架构中，CPU的启动和停止操作主要有两种方式：
1. **SBI HSM扩展**: 通过SBI (Supervisor Binary Interface) 的HSM (Hart State Management) 扩展
2. **Spinwait机制**: 传统的自旋等待机制

原始设计使用per-CPU数组 `cpu_ops[NR_CPUS]`，为每个CPU维护独立的操作函数指针。

### 3.2 设计缺陷

原始设计存在以下问题：
1. **冗余存储**: 所有CPU使用相同的操作函数，但每个CPU都存储一份指针
2. **初始化开销**: 需要为每个CPU单独调用 `cpu_set_ops()`
3. **内存浪费**: `NR_CPUS` 个指针占用不必要的内存空间

### 3.3 优化原理

#### 3.3.1 统一操作模式
RISC-V规范和现有实现中，CPU操作的选择基于以下逻辑：
```c
if (sbi_probe_extension(SBI_EXT_HSM)) {
    // 使用SBI HSM扩展
    cpu_ops = &cpu_ops_sbi;
} else {
    // 使用spinwait机制
    cpu_ops = &cpu_ops_spinwait;
}
```

这个选择是全局性的，不依赖于具体的CPU ID，因此所有CPU使用相同的操作函数。

#### 3.3.2 内存优化
- **修改前**: `sizeof(void*) * NR_CPUS` 字节
- **修改后**: `sizeof(void*)` 字节
- **节省**: `sizeof(void*) * (NR_CPUS - 1)` 字节

在64位系统中，假设 `NR_CPUS = 256`，可节省 `8 * 255 = 2040` 字节。

#### 3.3.3 初始化优化
- **修改前**: 需要循环调用 `cpu_set_ops(cpuid)` 为每个CPU设置操作
- **修改后**: 只需调用一次 `cpu_set_ops()` 设置全局操作

## 4. 代码变更详细分析

### 4.1 数据结构变更

```c
// 修改前
extern const struct cpu_operations *cpu_ops[NR_CPUS];

// 修改后  
extern const struct cpu_operations *cpu_ops;
```

### 4.2 初始化逻辑变更

```c
// 修改前的cpu_set_ops函数
void __init cpu_set_ops(int cpuid)
{
#if IS_ENABLED(CONFIG_RISCV_SBI)
    if (sbi_probe_extension(SBI_EXT_HSM)) {
        if (!cpuid)
            pr_info("SBI HSM extension detected\n");
        cpu_ops[cpuid] = &cpu_ops_sbi;
    } else
#endif
        cpu_ops[cpuid] = &cpu_ops_spinwait;
}

// 修改后的cpu_set_ops函数
void __init cpu_set_ops(void)
{
#if IS_ENABLED(CONFIG_RISCV_SBI)
    if (sbi_probe_extension(SBI_EXT_HSM)) {
        pr_info("SBI HSM extension detected\n");
        cpu_ops = &cpu_ops_sbi;
    }
#endif
}
```

### 4.3 使用方式变更

```c
// 修改前
if (cpu_ops[cpu]->cpu_start)
    return cpu_ops[cpu]->cpu_start(cpu, tidle);

// 修改后
if (cpu_ops->cpu_start)
    return cpu_ops->cpu_start(cpu, tidle);
```
