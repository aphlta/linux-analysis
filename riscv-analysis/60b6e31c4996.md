**guest_code 函数**:
```c
static void guest_code(void)
{
	struct sta_struct *st = st_gva;
	uint32_t sequence;
	uint64_t steal_time;
	uint64_t prev_steal_time = 0;
	int i;

	for (i = 0; i < NR_VCPUS; ++i) {
		if (sbi_probe_extension(SBI_EXT_STA) <= 0) {
			GUEST_SYNC(i);
			continue;
		}

		sbi_sta_steal_time_set_shmem(st_gva, 0, 0);
		GUEST_SYNC(i);

		check_status(st);
		sequence = READ_ONCE(st->sequence);
		steal_time = READ_ONCE(st->steal);
		TEST_ASSERT(steal_time >= prev_steal_time, "steal time decreased");
		prev_steal_time = steal_time;
		pr_info("VCPU%d: sequence=%d, flags=%d, steal=%ld, preempted=%d\n",
			i, sequence, st->flags, st->steal, st->preempted);
		GUEST_SYNC(i);
	}

	GUEST_DONE();
}
```
这是 guest 代码的主要逻辑，测试 steal time 功能。

static void steal_time_init(struct kvm_vcpu *vcpu, uint32_t addr_gpa)
{
	uint64_t addr = addr_gpa;

	vcpu_set_reg(vcpu, RISCV_SBI_STA_REG(shmem_lo), addr & 0xffffffff);
	vcpu_set_reg(vcpu, RISCV_SBI_STA_REG(shmem_hi), (addr >> 32) & 0xffffffff);
}

static void steal_time_dump(struct kvm_vcpu *vcpu, uint32_t addr_gpa)
{
	struct sta_struct *st = addr_gpa_to_hva(vcpu->vm, addr_gpa);

	pr_info("VCPU%d STA: sequence=%d, flags=%d, steal=%ld, preempted=%d\n",
		vcpu->id, st->sequence, st->flags, st->steal, st->preempted);
}

## 2. 代码修改原理

### 2.1 Steal Time 概念
Steal Time 是虚拟化环境中的一个重要概念，表示虚拟CPU被hypervisor抢占而无法运行的时间。这对于虚拟机内的时间管理和性能监控非常重要。

### 2.2 SBI STA 扩展
SBI (Supervisor Binary Interface) 是 RISC-V 架构中定义的标准接口，用于操作系统与固件/hypervisor之间的通信。STA (Steal Time Accounting) 扩展专门用于处理 steal time 统计。

### 2.3 共享内存机制
通过 `sbi_sta_struct` 结构体在 guest 和 host 之间共享 steal time 信息：
- `sequence`: 序列号，用于确保数据一致性
- `flags`: 标志位
- `steal`: 累计的 steal time
- `preempted`: 抢占状态

### 2.4 测试流程
1. Guest 探测 SBI STA 扩展支持
2. 设置共享内存区域
3. 读取和验证 steal time 数据
4. 确保 steal time 单调递增
