## 2. Ztso扩展技术原理

### 2.1 Ztso扩展概述

**Ztso (Total Store Ordering)** 是RISC-V的标准ISA扩展，用于提供全存储排序语义。

**核心特性:**
- 提供比RISC-V基础内存模型更强的内存排序保证
- 简化多线程程序的内存一致性编程模型
- 与x86的TSO (Total Store Ordering) 内存模型兼容

### 2.2 内存排序模型对比

| 内存模型 | 排序强度 | 特点 |
|----------|----------|------|
| RISC-V基础模型 | 弱排序 | 允许更多的内存访问重排，性能更高但编程复杂 |
| Ztso扩展 | 强排序 | 限制内存访问重排，简化编程模型 |
| x86 TSO | 强排序 | 工业标准，广泛应用于x86架构 |

### 2.3 Ztso的内存排序规则

1. **存储-存储排序:** 同一处理器的存储操作按程序顺序执行
2. **加载-加载排序:** 同一处理器的加载操作按程序顺序执行
3. **加载-存储排序:** 加载操作不能越过后续的存储操作
4. **存储原子性:** 存储操作对所有处理器呈现原子性

## 3. 代码修改原理分析

### 3.1 ISA扩展解析机制

RISC-V内核使用分层的ISA扩展管理机制：

```
设备树 "riscv,isa" 属性
        ↓
字符串解析 (cpufeature.c)
        ↓
内部标识符映射 (hwcap.h)
        ↓
ISA扩展位图设置
        ↓
运行时特性检测
```

### 3.2 关键数据结构

#### riscv_isa_ext数组

```c
const struct riscv_isa_ext_data riscv_isa_ext[] = {
    // ... 其他扩展
    __RISCV_ISA_EXT_DATA(ztso, RISCV_ISA_EXT_ZTSO),
    // ... 更多扩展
};
```

**作用:**
- 建立ISA扩展字符串与内部ID的映射表
- 支持设备树解析和运行时检测
- 提供扩展验证和依赖关系管理

#### __RISCV_ISA_EXT_DATA宏

```c
#define __RISCV_ISA_EXT_DATA(_name, _id) {  \
    .name = #_name,                     \
    .property = #_name,                 \
    .id = _id,                          \
}
```

**功能:**
- 自动生成ISA扩展数据结构
- 确保字符串名称与标识符的一致性
- 简化新扩展的添加过程
