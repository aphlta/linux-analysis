## Patch概述

这个patch为RISC-V架构添加了对Zfh和Zfhmin ISA扩展的解析支持。Zfh扩展提供了半精度（16位）浮点运算支持，而Zfhmin是Zfh的最小子集。

## 详细修改内容

### 1. 头文件修改 (arch/riscv/include/asm/hwcap.h)

```c
+#define RISCV_ISA_EXT_ZFH              66
+#define RISCV_ISA_EXT_ZFHMIN           67
```

**修改说明**:
- 在RISC-V ISA扩展定义中添加了两个新的扩展标识符
- ZFH扩展ID为66，ZFHMIN扩展ID为67
- 这些ID用于内核内部标识和管理这些ISA扩展

### 2. CPU特性解析修改 (arch/riscv/kernel/cpufeature.c)

```c
+       __RISCV_ISA_EXT_DATA(zfh, RISCV_ISA_EXT_ZFH),
+       __RISCV_ISA_EXT_DATA(zfhmin, RISCV_ISA_EXT_ZFHMIN),
```

**修改说明**:
- 在`riscv_isa_ext`数组中添加了zfh和zfhmin扩展的数据结构
- 使用`__RISCV_ISA_EXT_DATA`宏定义，将字符串名称与内部ID关联
- 这使得内核能够从设备树或其他源解析这些扩展

## 技术原理分析

### 1. ISA扩展解析机制

RISC-V内核使用统一的ISA扩展解析框架：

- **数据结构**: `riscv_isa_ext_data`结构体包含扩展名称和对应的内部ID
- **解析流程**: 内核启动时从设备树读取ISA字符串，通过`riscv_isa_ext`数组匹配扩展名称
- **位图管理**: 使用位图(`isa_bitmap`)来跟踪CPU支持的扩展

### 2. Zfh/Zfhmin扩展特性

**Zfh扩展**:
- 提供完整的半精度浮点运算支持
- 包括算术运算、比较、转换等操作
- 支持IEEE 754-2008半精度格式

**Zfhmin扩展**:
- Zfh的最小子集
- 主要提供半精度浮点数的加载、存储和转换操作
- 不包括完整的算术运算

### 3. 内核集成机制

- **hwcap导出**: 通过`/proc/cpuinfo`向用户空间导出扩展信息
- **运行时检测**: 应用程序可以通过hwprobe系统调用检测扩展支持
- **编译器支持**: 配合GCC/LLVM的-march参数使用
