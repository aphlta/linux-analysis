## Patch 概述

这个patch优化了RISC-V架构中T-HEAD CPU的缓存管理操作(CMO)实现，将原来基于虚拟地址的缓存操作指令改为使用基于物理地址的指令，从而避免了虚拟地址到物理地址的转换开销。

## 详细修改内容

### 修改的文件
- `arch/riscv/errata/thead/errata.c` (18行修改: +6, -12)

### 核心修改

#### 1. T-HEAD CMO指令编码更新

**修改前 (虚拟地址指令):**
```c
#define THEAD_INVAL_A0 ".long 0x0265000b"  // th.dcache.iva (invalidate, virtual address)
#define THEAD_CLEAN_A0 ".long 0x0255000b"  // th.dcache.cva (clean, virtual address) 
#define THEAD_FLUSH_A0 ".long 0x0275000b"  // th.dcache.civa (clean then invalidate, virtual address)
```

## 技术原理分析

### T-HEAD CMO指令编码分析

T-HEAD CPU支持两套缓存管理指令:

#### 虚拟地址指令 (修改前使用)
- `th.dcache.iva rs1` - 基于虚拟地址的缓存无效化
- `th.dcache.cva rs1` - 基于虚拟地址的缓存清理
- `th.dcache.civa rs1` - 基于虚拟地址的缓存清理并无效化

#### 物理地址指令 (修改后使用)
- `th.dcache.ipa rs1` - 基于物理地址的缓存无效化
- `th.dcache.cpa rs1` - 基于物理地址的缓存清理
- `th.dcache.cipa rs1` - 基于物理地址的缓存清理并无效化

### 指令编码格式

所有T-HEAD CMO指令都遵循相同的32位编码格式:
```
| 31-25 | 24-20 | 19-15 | 14-12 | 11-7 | 6-0 |
| func7 | func5 |  rs1  | func3 | rd   | op  |
```

关键差异在于func5字段:
- 虚拟地址指令: `00110` (iva), `00101` (cva), `00111` (civa)
- 物理地址指令: `01010` (ipa), `01001` (cpa), `01011` (cipa)

### 性能优化原理

1. **消除地址转换开销**: 原来需要调用`phys_to_virt()`进行地址转换，现在直接使用物理地址
2. **减少内存访问**: 避免了虚拟地址映射查找的开销
3. **简化代码路径**: 减少了函数调用和中间变量

## 性能提升

1. **减少CPU周期**: 消除`phys_to_virt()`调用开销
2. **降低内存带宽**: 减少地址转换相关的内存访问
3. **提高缓存效率**: 直接操作物理地址，避免TLB查找
4. **简化执行路径**: 减少分支和函数调用

## 兼容性考虑

- **向后兼容**: 不影响不支持物理地址CMO的CPU
- **运行时检测**: 通过errata框架自动检测和启用
- **配置控制**: 可通过内核配置选项控制

## 代码质量改进

1. **代码简化**: 每个函数减少2行代码
2. **可读性提升**: 消除中间变量，逻辑更直接
3. **维护性**: 减少潜在的地址转换错误
