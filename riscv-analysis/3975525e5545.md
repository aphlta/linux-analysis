#### 3.1.2 添加Vector寄存器索引复制函数

```c
static int copy_vector_reg_indices(const struct kvm_vcpu *vcpu,
                               u64 __user *uindices)
{
    const struct kvm_cpu_context *cntx = &vcpu->arch.guest_context;
    int n = num_vector_regs(vcpu);
    u64 reg, size;
    int i;

    if (n == 0)
        return 0;

    /* copy vstart, vl, vtype, vcsr and vlenb */
    size = IS_ENABLED(CONFIG_32BIT) ? KVM_REG_SIZE_U32 : KVM_REG_SIZE_U64;
    for (i = 0; i < 5; i++) {
        reg = KVM_REG_RISCV | size | KVM_REG_RISCV_VECTOR | i;

        if (uindices) {
            if (put_user(reg, uindices))
                return -EFAULT;
            uindices++;
        }
    }

    /* vector_regs have a variable 'vlenb' size */
    size = __builtin_ctzl(cntx->vector.vlenb);
    size <<= KVM_REG_SIZE_SHIFT;
    for (i = 0; i < 32; i++) {
        reg = KVM_REG_RISCV | KVM_REG_RISCV_VECTOR | size |
                KVM_REG_RISCV_VECTOR_REG(i);

        if (uindices) {
            if (put_user(reg, uindices))
                return -EFAULT;
            uindices++;
        }
    }

    return n;
}
```

**分析**:
- 为Vector CSR和Vector寄存器生成KVM寄存器ID
- Vector CSR使用固定大小（32位或64位，取决于架构）
- Vector寄存器使用可变大小，基于vlenb值计算
- 使用`__builtin_ctzl()`计算vlenb的对数值作为大小编码

## 4. 技术原理分析

### 4.1 RISC-V Vector扩展架构

RISC-V Vector扩展(RVV)提供了以下关键组件：

1. **Vector寄存器**: 32个向量寄存器(v0-v31)，每个寄存器的长度由VLEN参数决定
2. **Vector CSR**:
   - `vstart`: Vector起始元素索引
   - `vl`: Vector长度
   - `vtype`: Vector类型配置
   - `vcsr`: Vector控制状态寄存器
   - `vlenb`: Vector长度（以字节为单位）

### 4.2 KVM寄存器ID编码

KVM使用64位寄存器ID来唯一标识每个寄存器：

```
[63:52] - KVM_REG_ARCH_MASK (架构标识)
[51:32] - KVM_REG_SIZE_MASK (寄存器大小)
[31:24] - KVM_REG_RISCV_TYPE_SHIFT (RISC-V寄存器类型)
[23:0]  - 寄存器编号
```

对于Vector寄存器，类型为`KVM_REG_RISCV_VECTOR` (0x09)。

### 4.3 可变大小寄存器处理

Vector寄存器的大小是可变的，取决于硬件实现的VLEN参数：
- VLEN可以是128、256、512、1024等2的幂次
- vlenb = VLEN / 8（以字节为单位）
- 使用`__builtin_ctzl(vlenb)`计算log2(vlenb)作为大小编码

### 4.4 KVM One-Reg接口

KVM One-Reg接口是KVM提供的标准化寄存器访问机制：
- `KVM_GET_REG_LIST`: 枚举所有可用寄存器
- `KVM_GET_ONE_REG`: 读取单个寄存器值
- `KVM_SET_ONE_REG`: 设置单个寄存器值

这个接口支持虚拟机的状态保存/恢复和实时迁移。

## 5. Vector扩展状态结构

根据`arch/riscv/include/uapi/asm/ptrace.h`中的定义：

```c
struct __riscv_v_ext_state {
    unsigned long vstart;
    unsigned long vl;
    unsigned long vtype;
    unsigned long vcsr;
    unsigned long vlenb;
    void *datap;
};
```

- `datap`指向实际的Vector寄存器数据
- Vector寄存器数据的大小为`32 * vlenb`字节
- 最大Vector长度为8192字节(`RISCV_MAX_VLENB`)
