## 1. Patch概述

这个patch为RISC-V架构添加了对Vector Crypto（向量加密）ISA扩展的解析支持。这些扩展定义在"RISC-V Cryptography Extensions Volume II"规范中，为RISC-V处理器提供了硬件加速的向量加密操作能力。

## 2. 修改的文件

### 2.1 arch/riscv/include/asm/hwcap.h
- **修改内容**: 添加了15个新的ISA扩展宏定义
- **新增扩展ID**: 从RISCV_ISA_EXT_ZVBB (56) 到 RISCV_ISA_EXT_ZVKT (65)

### 2.2 arch/riscv/kernel/cpufeature.c
- **修改内容**: 添加了bundled extensions数组定义和ISA扩展数据结构
- **新增代码行数**: 64行

## 3. 支持的Vector Crypto扩展

### 3.1 基础扩展
- **Zvbb**: Vector Basic Bit-manipulation - 向量基础位操作
- **Zvbc**: Vector Carryless Multiplication - 向量无进位乘法
- **Zvkb**: Vector Cryptography Bit-manipulation - 向量加密位操作
- **Zvkg**: Vector GCM/GMAC - 向量GCM/GMAC算法支持
- **Zvkt**: Vector Data-Independent Execution Latency - 向量数据无关执行延迟

### 3.2 NIST算法套件
- **Zvkned**: NIST Suite: Vector AES Block Cipher - 向量AES块密码
- **Zvknha**: NIST Suite: Vector SHA-2 Secure Hash (SHA-256) - 向量SHA-256
- **Zvknhb**: NIST Suite: Vector SHA-2 Secure Hash (SHA-512) - 向量SHA-512
- **Zvkn**: NIST Algorithm Suite - NIST算法套件
- **Zvknc**: NIST Algorithm Suite with carryless multiply - 带无进位乘法的NIST套件
- **Zvkng**: NIST Algorithm Suite with GCM - 带GCM的NIST套件

### 3.3 ShangMi算法套件
- **Zvksed**: ShangMi Suite: SM4 Block Cipher - 向量SM4块密码
- **Zvksh**: ShangMi Suite: SM3 Secure Hash - 向量SM3安全哈希
- **Zvks**: ShangMi Algorithm Suite - 商密算法套件
- **Zvksc**: ShangMi Algorithm Suite with carryless multiplication - 带无进位乘法的商密套件
- **Zvksg**: ShangMi Algorithm Suite with GCM - 带GCM的商密套件

## 4. 技术实现细节

### 4.1 Bundled Extensions机制

Patch使用了bundled extensions机制来管理复合扩展：

```c
// NIST套件定义
#define RISCV_ISA_EXT_ZVKN \
    RISCV_ISA_EXT_ZVKNED, \
    RISCV_ISA_EXT_ZVKNHB, \
    RISCV_ISA_EXT_ZVKB, \
    RISCV_ISA_EXT_ZVKT

// ShangMi套件定义
#define RISCV_ISA_EXT_ZVKS \
    RISCV_ISA_EXT_ZVKSED, \
    RISCV_ISA_EXT_ZVKSH, \
    RISCV_ISA_EXT_ZVKB, \
    RISCV_ISA_EXT_ZVKT
```

### 4.2 扩展注册机制

使用不同的宏来注册不同类型的扩展：
- `__RISCV_ISA_EXT_DATA`: 基础扩展
- `__RISCV_ISA_EXT_BUNDLE`: 复合扩展
- `__RISCV_ISA_EXT_SUPERSET`: 超集扩展

### 4.3 验证机制

后续的commit (38077ec8fc11) 添加了验证机制，确保vector crypto扩展只有在vector扩展可用时才能启用。

## 5. 代码修改原理

### 5.1 HWCAP扩展

在`hwcap.h`中添加新的扩展ID，这些ID用于：
- 内核内部识别和管理扩展
- 用户空间通过`/proc/cpuinfo`查询扩展支持
- 动态库和应用程序检测硬件能力

### 5.2 ISA字符串解析

在`cpufeature.c`中的`riscv_isa_ext`数组定义了ISA字符串的解析规则：
- 按照RISC-V规范的字母顺序排列
- 支持复合扩展的自动展开
- 提供扩展间的依赖关系管理

### 5.3 运行时检测

通过`riscv_isa_extension_available()`函数，内核和用户空间可以在运行时检测特定扩展的可用性。
